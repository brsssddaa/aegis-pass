# Aegis Pass // Sync Server & Web Vault

Сверхбыстрый автономный сервер синхронизации и веб-хранилище для проекта **Aegis Pass**.

## Возможности

1. **Кроссплатформенный доступ без установки:**
   - Открывается в любом браузере на телефоне (**Poco X7 Pro**, Android, iOS) или любом другом компьютере в локальной сети / Tailscale.
   - PWA (Progressive Web App): можно нажать «Установить на главный экран» в браузере телефона, и хранилище будет работать как нативное приложение со своим ярлыком и оффлайн-кэшем.

2. **Двусторонняя мгновенная синхронизация (Real-Time Live Sync):**
   - Использует Server-Sent Events (SSE). При добавлении или изменении пароля на ПК — экран телефона обновляется автоматически в реальном времени за доли секунды.
   - При добавлении пароля с телефона — файл на ПК обновляется атомарно и мгновенно.

3. **Безопасность и автоматические бэкапы:**
   - Защита PIN-кодом (по умолчанию: `2026`).
   - Автоматическое создание резервной копии базы в папку `server/backups/` перед каждой записью.
   - Ротация до 20 последних бэкапов.
   - Кнопка выгрузки полного бэкапа в 1 клик.

4. **Генератор безопасных паролей:**
   - Встроенный кибер-генератор паролей с настройкой длины (8–64 символов), заглавных, строчных букв, цифр и спецсимволов.
   - Индикатор надежности пароля.

## Адреса для подключения

- **С этого компьютера (Local):** [http://127.0.0.1:8088](http://127.0.0.1:8088)
- **С телефона в домашней сети Wi-Fi (LAN):** [http://192.168.5.4:8088](http://192.168.5.4:8088)
- **С телефона везде через Tailscale VPN:** [http://100.109.8.27:8088](http://100.109.8.27:8088)

**PIN-код для входа по умолчанию:** `2026`

## Запуск сервера

- **Через батник:** двойной клик по `start_server.bat` в папке проекта.
- **Через терминал:** `npm run server` или `node server/server.js`.
- **Автоматически:** сервер встроен в приложение Electron `Aegis Pass` и автоматически запускается вместе с ним.
